Camcor Manufacturing

Conveyor stopping mechanism
Oil soaking mechanism
Smaller pallet design
Vent plug pulling tool
Induction heating table
Pinion gear fixtures

A collection of mechanical design solutions developed under the supervision of the design engineer at Camcor Manufacturing:

  • Conveyor cart for rejected pallet parts. Designed a lever to disconnect the conveyor driveshaft and lift the pallet part with the mechanism.
  • Oil soaking mechanism that prevents oil from reaching electrical pins
  • Compact pallet design for quality testing parts
  • Vent plug pulling tool with smooth-fitting components
  • Induction heating table for welded gears

EV3 Robot

Developed a Lego EV3 robot with Robot C programming that can move red cups outside the range of its ultrasonic sensor by picking them up. Using lowering mechanisms and 3D-printed claws to pick up the cups.

RC Car

Created a prototype Self-Driving RC Car that uses machine learning algorithms to determine whether or not to turn. Uses a rack and pinion steering system with back-wheel drive.

  • Raspberry Pi controlled with motor controller
  • 30 FPS camera for continuous software updates
  • Machine learning for autonomous navigation

QuakeMaster

Created a Shake Table Toy similar to Jenga Quake using a system of cam mechanisms to lift the various tiles of the Shake Table and move the blocks.

  • Interconnecting pins for creative block arrangements
  • Cam mechanism system for realistic earthquake simulation
  • Educational toy for understanding structural stability
