Temporary E-Stop Mechanism
What

Designed a relay system using a self latching system to control relay using states.

How

The relay system uses three states to prevent power from flowing through to output signals. Once E-Stop is pressed the latch will shift and disallow power to the outputs. Designed PCB for relay mounts and expandability for more outputs. Integrated PLC real-time monitoring using Structured Text programming.

Results

Was effective for a temporary solution before permanent safety solution is put in place. Effectively stopped outputs.

Induction heating table
What

Designed an induction heating table to hold an industrial grade laser welding machine to weld ring gears for a Power Transfer Unit.

How

Used McMaster-Carr parts and custom designed parts to be fabricated out of sheet metal, to hold the pinion ring gear assembly for weldment at the correct height.

Results

Consistent heating profile achieved, resulting in stronger welds and fewer defects. In addition, optimized production worker efficiency by 36.7% by allowing for easier mounting without manually the part for weldment.

RC Car (Work in Progress)

RC Car
What

Built a prototype self-driving RC car with real-time perception and steering control.

How

Captured frames on the Pi, normalized and resized inputs for a late-fusion PyTorch CNN, applied a confidence threshold with a rolling vote over recent frames, then output discrete left/right commands. The Pi sent serial commands to an Arduino that generated PWM for the steering servo and ESC, with rate limiting and a neutral fallback when confidence dropped.

Results

Achieved consistent obstacle-avoidance turns with ~90% left/right accuracy and built a 3D-printed double-wishbone chassis with a spur-gear diff and rack-and-pinion steering. Currently working on suspension issues.

Created a prototype Self-Driving RC Car that uses machine learning algorithms to determine whether or not to turn. Uses a rack and pinion steering system with back-wheel drive.
